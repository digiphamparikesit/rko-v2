3Setup Awal Sistem

⚠️ Hanya Sekali
Setup awal cukup dilakukan sekali saat sistem baru dipasang.
  1. Master Prinsipal
    Tambah nama prinsipal → master-prinsipal.html
  2. Master Distributor
    Isi nama, kontak, lead time default → master-distributor.html
  3. Master Ruangan
    Isi nama, jenis, status → master-ruangan.html
  4. Master Barang
    Isi detail barang, HPP, prinsipal, gudang → admin.html
  5. Manajemen User
    Buat akun untuk semua role → manajemen-user.html
  6. Pengaturan Periode RKO
    Atur tanggal buka & tutup RKO → pengaturan-rko.html

Peran Pengguna

Admin

ADMIN

Mengelola data master dan konfigurasi sistem. Tidak memiliki akses approval & delegasi.

1Menu yang Bisa Diakses

Hampir semua menu, kecuali Approval Edit Penerimaan & Delegasi Approval.

❌ Tidak Bisa Akses
Approval Edit Penerimaan & Delegasi Approval — hanya untuk Kepala IF / Koordinator.

2Panduan per Menu

🛠️ Master Barang (admin.html)

  1. Buka menu Master Barang
  2. Tambah baru
    Klik + Tambah Barang → isi form → Simpan.
  3. Edit
    Klik ikon pensil → ubah → Simpan.
  4. Nonaktifkan
    Ubah toggle "Status Aktif" → jangan hapus, histori tetap terjaga.

🏥 Master Ruangan

Isi nama, jenis (BESAR / KECIL), status aktif.

🚛 Master Distributor

Isi nama, kontak, lead time default (hari). Lead time dipakai untuk kalkulasi buffer.

🏭 Master Prinsipal

Isi nama prinsipal, relasikan ke barang saat input Master Barang.

👥 Manajemen User

  1. Buat user baru
    Klik + Tambah User → isi email, nama, role, ruangan → Simpan.
  2. Reset password
    Klik Reset pada baris user.
  3. Nonaktifkan user
    Ubah status aktif → user tidak bisa login.

🔐 Pengaturan Periode RKO

Pilih bulan & tahun → atur tanggal buka & tutup → Simpan.

2Verifikasi Retur Barang

Kapan: setelah distributor konfirmasi terima (status DITERIMA_DIST).

  1. Buka menu Retur Barang
    Filter status DITERIMA_DIST.
  2. Review retur
  3. Klik Verifikasi Selesai
    Status jadi SELESAI.
DRAFT→ DIKIRIM→ DITERIMA_DIST→ SELESAI

3Approval Usulan Pembelian

  1. Buka menu Usulan Pembelian
    Filter status DIUSULKAN.
  2. Review usulan
  3. Setujui / Tolak

4Delegasi Approval

  1. Buka menu Delegasi Approval
  2. Klik + Buat Delegasi
  3. Isi form
    Penerima, tanggal mulai & berakhir, alasan.
  4. Simpan
💡 Tips
Buat delegasi jauh hari sebelum cuti supaya tidak ada approval tertahan.

Peran Pengguna

Petugas Mutasi Obat

PETUGAS_MUTASI_OBAT

Khusus menangani mutasi obat dari gudang ke ruangan + stok opname gudang.

1Menu yang Bisa Diakses

📊Dashboard RKO
🚚Mutasi ke Ruangan
📋Riwayat Mutasi
🔎Monitoring RKO
📥Stok Opname Gudang
🔒Ubah Password
💡 Filter
Di semua form, filter gudang = OBAT.

2Mutasi Obat ke Ruangan

  1. Buka menu Mutasi ke Ruangan
  2. Pilih barang
  3. Sistem tampilkan alokasi proporsional
  4. Review & sesuaikan qty
  5. Klik Konfirmasi Mutasi

3Koreksi Mutasi

  1. Buka Riwayat Mutasi
  2. Cari mutasi yang perlu dikoreksi
  3. Klik Edit
  4. Isi alasan koreksi
    Wajib — untuk audit trail.

4Tips

  • Cek RKO terbaru sebelum mutasi.
  • FIFO/FEFO — prioritaskan kadaluarsa terdekat.
  • Koreksi selalu butuh alasan.

Petugas Mutasi BMHP

PETUGAS_MUTASI_BMHP

Khusus menangani mutasi BMHP dari gudang ke ruangan.

1Menu yang Bisa Diakses

📊Dashboard RKO
🚚Mutasi ke Ruangan
📋Riwayat Mutasi
🔎Monitoring RKO
📥Stok Opname Gudang
🔒Ubah Password
💡 Filter
Di semua form, filter gudang = BMHP.

2Panduan Detail

Panduan sama persis dengan Petugas Mutasi Obat, hanya berbeda filter:

Di Mutasi ObatDi Mutasi BMHP
Filter gudang = OBATFilter gudang = BMHP
Barang: obat-obatanBarang: Bahan Medis Habis Pakai

3Tips Khusus BMHP

  • BMHP sering dipakai di IGD, OK, ICU — cek pola pemakaian sebelum mutasi besar.
  • Barang dengan kadaluarsa dekat jangan dimutasi ke ruangan dengan pemakaian lambat.
  • Batch tracking penting — pastikan nomor batch sesuai.

Tim Penerimaan

TIM_PENERIMAAN

Menerima barang datang dari distributor dan mencatat kondisi termasuk barang rusak.

1Menu yang Bisa Diakses

📊Dashboard RKO
📦Penerimaan Barang
🔄Retur Barang
🔒Ubah Password

2Input Penerimaan Barang

  1. Buka menu Penerimaan Barang
  2. Pilih PO
  3. Isi per barang
    Qty diterima, No. batch, kadaluarsa, Kondisi (BAIK/RUSAK).
  4. Simpan
  5. Barang RUSAK otomatis berstatus MENUNGGU_RETUR

3Buat Surat Retur

  1. Buka menu Retur Barang
  2. Klik + Buat Retur Baru
  3. Pilih Penerimaan Rusak
  4. Review daftar barang rusak
  5. Isi form
    Tanggal, alasan utama, catatan.
  6. Simpan Retur
    Status jadi DRAFT

4Alur Lengkap Retur

DRAFT→ DIKIRIM→ DITERIMA_DIST→ SELESAI
AksiMenuStatus
Buat retur+ BuatDRAFT
Kirim ke distributorKlik KirimDIKIRIM
Konfirmasi terimaKlik Konfirmasi DiterimaDITERIMA_DIST
Verifikasi finalKepala IF / KoordinatorSELESAI
BatalkanKlik BatalkanDIBATALKAN

PertanyaanJawaban

Tim Pembelian

TIM_PEMBELIAN

Membuat dan mengelola Purchase Order (PO) ke distributor.

1Menu yang Bisa Diakses

📊Dashboard RKO
🛒Pembelian (PO)
🔒Ubah Password

2Alur PO

Usulan DISETUJUI→ PO DRAFT→ PO DIKIRIM→ Barang Diterima

3Buat PO dari Usulan Disetujui

  1. Buka menu Pembelian (PO)
  2. Filter usulan status DISETUJUI
  3. Klik Buat PO
  4. Isi form PO
    No. PO, distributor, tanggal, qty.
  5. Simpan
    Status DRAFT.

4Kirim PO & Ganti Distributor

  1. Cari PO status DRAFT
  2. Review ulang
  3. Klik Kirim
    Status jadi DIKIRIM.
  4. Ganti distributor
    Klik Ubah Distributor → isi alasan → Simpan.
